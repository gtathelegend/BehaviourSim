10. PROBABLE ROOT CAUSE & RECOMMENDED CORRECTION
-------------------------------------------------------------------------------
Root Cause:
  The default simulation parameter `num_interactions_per_learner = 100` generates a single
  learner sequence of 100 interactions per profile. Due to the strict overload target definition
  (prior_acc >= 0.75 AND future_acc <= 0.50), a single 100-interaction sequence yields 0
  (or 1-2) positive overload targets for most profiles.
  Supervised machine learning cross-validation and XGBoost tree training cannot train non-trivial
  models or calculate ROC AUC when the target contains 0 positive examples.

Recommended Correction:
  1. Increase `num_interactions_per_learner` in config.py (or simulate multiple learners per
     profile, e.g., num_interactions_per_learner = 500 or 1000).
  2. With 500+ interactions per profile, every profile will contain 15-30 positive overload
     target events. 5-fold TimeSeriesSplit CV will successfully train non-trivial XGBoost models,
     collect complete OOF predictions for all 5 profiles, compute valid ROC AUCs for Figure 2,
     generate non-zero SHAP feature importances for Figure 3, plot visible comparison bars for
     Figure 5, and align cleanly with Figure 4.
